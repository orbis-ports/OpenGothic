# /data/orbis-env.txt — optional: driver knobs and OpenGothic switches, without a rebuild
#
# ⚠ THIS FILE GOES TO /data/orbis-env.txt, NOT /data/tempest-env.txt. The old name still works and is
# still read - packages already on consoles only know that one - but it is DEPRECATED as of
# 2026-09-18 and will be dropped once no release in circulation writes it.
#
# ⚠ AND THE NEW NAME IS THE ONLY ONE A CORE CAN SEE. setenv() in one image is invisible to another
# here: the SDK's libc.a is a real static musl, so an eboot and every .prx it loads each carry their
# own `environ`. Measured 2026-08-23 - ORBIS_NCPU=1 written into /data/retroarch-env.txt was applied
# to the frontend and never reached the core, which still started 5 recompiler workers, and the run
# read as a clean measurement. Anything inside a loadable module therefore reads the FILE itself,
# through orbis-compat's orbis_env_get, and that reader cannot know which product loaded it - so it
# reads one well-known path. That path is /data/orbis-env.txt.
#
# ⚠ A NORMAL RUN NEEDS NO FILE AT ALL. The driver ships the configuration it was tested in: 3D images
# are LINEAR_ALIGNED, tessellation is advertised and its factor ring is backed at Sony's address - all
# by default. An absent file is a clean run, and the title says so in its log ("env: no
# /data/orbis-env.txt"). This file is for turning a diagnostic ON, or a default OFF, for one run.
#
# ⚠ EVERY TITLE ON THE CONSOLE READS THIS FILE - that is the point of the shared name, and it is the
# cost of it. RetroArch applies it first, before its own /data/retroarch-env.txt; OpenGothic applies
# it first, before /data/tempest-env.txt. A knob left here reaches every run of both - which is how a
# watermark left in on 2026-09-01 froze RetroArch's menu for 1.5 s every 768 frames. Take a knob out
# when its run is done.
#
# The title reads it as the first thing after ps4_app_init and setenv()s every line, overriding the
# process environment. Every applied line is echoed to the title's log. To change it:
#
#     lftp -p 2121 192.168.100.2 -e "cd /data; put orbis-env.txt; bye"
#
# Syntax: KEY=VALUE, one per line. Blank lines and lines starting with # are ignored, and whitespace around both
# sides of the '=' is trimmed — a trailing space in "7:314 " would otherwise read as a different experiment.
#
# ---------------------------------------------------------------- defaults that can be switched OFF
#   ORBIS_3D_LINEAR=0         tiled 3D images again. They fault this GPU on entering the world
#   ORBIS_NO_TESS=1           do not advertise tessellation (costs GL 4.6 / ES 3.2 too)
#   ORBIS_TF_SONY_BASE=0      use our own tessellation factor ring - the pre-2026-08-31 fault.
#                             =<addr>[:<MiB>] moves the backing instead
#
# ---------------------------------------------------------------- diagnostics, all OFF by default
#   MESA_LOG_FILE=<path>      where mesa_log writes; WITHOUT IT THE DRIVER IS MUTE (stderr is lost on this console).
#                             Give it a name of its own: a deqp name here once overwrote 4.3 MB of CTS baseline
#   MESA_LOG_LEVEL=info       anything below info hides the traces below
#   ORBIS_DRM_TRACE=1         the PS4 arm's own trace (submissions, stages, waits)
#   RADV_DEBUG=info,nohiz     RADV's own flags; nohiz allocates no HTILE
#   ORBIS_DUMP_SUBMIT=<n>     hexdump submission n and the IBs it chains to (0 = every one, which is a lot)
#   ORBIS_TRUNCATE=<n>:<dw>   cut submission n to dw dwords and still append the fence. THE CUT MUST LAND ON A
#                             PACKET BOUNDARY — take the offset from an UNTRUNCATED dump of the same build
#   ORBIS_CMASK=1             put single-sample CMASK back (it faults this GPU)
#   ORBIS_TILE_MODE=1d        clamp 2D tiling to 1D (2D surfaces only)
#   ORBIS_ARENA_MIB=<n>       the direct-memory arena's size, for when an allocation is refused
#   ORBIS_TRACE_SUBMITS=<n>   trace the first n submissions through every stage; 0 = every one
#   ORBIS_SCAN_VA=<dw>[:<mask>][,...]  scan every mapped BO for that dword and print "handle H offset O".
#                             Up to 8 comma-separated patterns in one pass; a mask compares only those bits
#   ORBIS_SCAN_EVERY=<n>      scan before every nth submission (512 by default)
#   ORBIS_SCAN_AT=<n>         scan before submission n only, instead of a stride
#   ORBIS_SCAN_MAX_MIB=<n>    how much a scan may read (256). WHAT IT SKIPPED IS PRINTED - read that field
#   ORBIS_TRACE_BOS=1         print every mapping's VA range once, so a faulting address can be placed
#   ORBIS_TESS_RING_WATERMARK=<n>  report every nth submission how far the hardware wrote into the
#                             tessellation rings. Costs a scan of the whole ring on the submit path
#
# ---------------------------------------------------------------- OpenGothic
#   OG_ARGS=<switches>        extra command-line switches, space-separated: `OG_ARGS=-rt 0 -window`
#
# ⚠ EVERY NAME ABOVE WAS CHECKED FOR A READER ON 2026-09-15 (`grep -rl '"NAME"' src/` in mesa-ps4; OG_ARGS
# in game/main.cpp). ORBIS_NO_PREFETCH, ORBIS_MAX_INSTANCES and TEMPEST_PS4_KBD were once documented here
# with nothing reading them. A file that tells an operator to set a line that does nothing is worse than
# one that omits it: the run comes back clean and reads as a measurement. Re-run the check when adding one.
